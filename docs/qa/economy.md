# Независимая проверка экономики

## Воспроизводимость

Из корня репозитория:

```sh
node scripts/simulate-economy.mjs --fixture
node --test tests/economy-analysis/*.test.mjs
node --import tsx scripts/simulate-economy.mjs
npm run check
```

Первый запуск использует эталонный синтетический каталог и независимую модель; последний запуск симулятора (без `--fixture`) использует реальные `loadContent`, `createProgression`, `credit` и `sellRefund`. Нет автоматического fallback при ошибке каталога. Результаты раздельно пишутся в `validation/economy/fixture` и `validation/economy/live`: `routes.csv`, `checkpoints.csv`, `summary.json`, `recommended-values.json`. CSV содержит остаток печатей и их расход, отдельно от начисленных/свободных очков, глубину ветки, первый T30, максимальный интервал без покупки и максимум заблокированных печатями очков.

## Сценарии и методика

20 последовательных сюжетных побед на рекомендованных difficulty. Кампания без знаний — арифметический контроль; обычная кампания покупает узлы по мере доступа. Разнообразный маршрут после кампании перебирает карты групп 2–4, режимы и сложности normal/hard/extreme, распределяет покупки по ширине; эксперт выбирает наиболее выгодные испытания группы 4, покупает узлы по глубине. Повторитель проходит первую карту на easy/standard без других открытий. Retry проигрывает перед каждой сюжетной победой и перед каждой третьей победой в испытаниях, с отдельным runId. Поражение приходится на середину волн и занимает 55% полного времени. Сюжетные prerequisites проверяются до открытия соответствующих испытаний. Условие успешной боевой стратегии не доказывается этими маршрутами.

Время групп 12/18/25/32 минуты для 40/60/80/100 волн; для других difficulty пропорционально числу волн. Overdrive условно на 10% быстрее; чувствительность 0,7/1/1,3 изменяет только оценку реального времени. Вероятности побед и время требуют калибровки по ручным прохождениям и replay. Синтетические знания дают бонусы к XP/печатям по 2% на каждом пятом узле маяка/снабжения, до 10%; эффекты не представляют фактический каталог веток 75–79. Покупки происходят только при наличии очка, печатей, уровня и prerequisites. Лимит 12000 попыток отмечается `limit`, а не успехом.

Сравнение предполагает победу; при низкой вероятности успеха строгий режим может быть менее выгоден. Учитывать время неудач, а не только побед.

## Предложение по балансу

Вместо [200,40,5] рассмотреть [200,60,4]: кампания 51 очко, разнообразный маршрут 51,64 ч, эксперт 37,97 ч, retry 62,89 ч. Кривая уменьшает позднюю нагрузку, не ускоряя начальные уровни чрезмерно. Печати и цена узлов без изменений. Выбор из пяти вариантов минимизирует отклонения номинальных маршрутов от 35–65 ч и кампании от 30–55 очков. Временная чувствительность сохраняется; при +30% retry всё ещё выходит за коридор. Не применять до сверки реального каталога и replay. `recommended-values.json` — предложение, не изменение общей конфигурации.

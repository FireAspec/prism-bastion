# Игра с друзьями

## В одной локальной сети

1. Установите одну и ту же версию Prism Bastion на всех компьютерах. Хост открывает «Игра с друзьями» → «Создать комнату».
2. Введите имя (до 24 символов), выберите карту, сложность, режим, количество мест (2–4), порт (по умолчанию 43127). Пароль необязателен. Передавайте его отдельно от адреса.
3. Скопируйте адрес подходящего сетевого адаптера из списка. Если IP несколько, используйте тот, который относится к общей сети. Не передавайте localhost или 127.0.0.1 друзьям.
4. Остальные игроки открывают «Подключиться», вводят имя, IP и порт хоста, пароль при наличии. Можно вставить скопированный адрес вместе с портом; порт в адресе имеет приоритет. IPv6 с портом записывается в квадратных скобках: `[::1]:43127`.
5. Нажмите «Готов». Хост подтверждает запуск при наличии не менее двух подключённых участников. Он может явно подтвердить запуск без полной готовности.

## Через интернет

Бесплатная виртуальная LAN: [Radmin VPN — официальный сайт](https://www.radmin-vpn.com/). Установите её самостоятельно при необходимости, создайте закрытую сеть на одном ПК, подключите друзей к той же сети. Используйте адрес хоста из Radmin VPN и порт комнаты, а не публичный IP роутера. Игра не устанавливает VPN и не обходит NAT автоматически. Аккаунт или платный игровой сервер не требуются. При прямом подключении через интернет доступность порта зависит от сети и маршрутизатора. Используйте только доверенную сеть: протокол v1 использует обычный WebSocket, а пароль комнаты не заменяет защищённый канал связи.

## Если не получается подключиться

- Проверьте, что хост не закрыл игру, адрес и порт правильные, и игроки находятся в одной физической или виртуальной LAN.
- Разрешите приложению входящие подключения в брандмауэре Windows для нужной доверенной сети. Не отключайте брандмауэр целиком.
- При ошибке версии или контента обновите игру всех участников до одинаковой сборки. При неверном пароле запросите его у хоста.
- При обрыве не закрывайте лобби: приложение пытается восстановить соединение в течение 120 секунд; после истечения срока вернитесь в меню. Миграции хоста нет. Хост сохраняет забег при остановке согласно сетевому модулю.

## Правила команды

Кредиты и жизни общие. Каждый строит на общей карте, но улучшение, продажа, приоритет и способность принадлежат владельцу башни. Хост может забрать осиротевшие башни после 30 секунд отключения владельца. Паузой и скоростью управляет хост. Новая волна начинается при готовности всех или по решению хоста. Слот T5 общий для команды. Сервер подтверждает покупки и предотвращает одновременные траты сверх бюджета.

## Интеграция лобби

`createLobby(root, config, hooks, locale?)` реализует `LobbyUI`. DOM не создаёт сокеты, не запускает сервер и не вычисляет баланс. `show(profile)` открывает форму; `update(room,status)` получает авторитетную комнату; `hide()` скрывает и очищает представление; `dispose()` дополнительно удаляет принадлежащий лобби DOM. `leave()` передаётся приложению при нажатии «Назад» или «Покинуть комнату». Приложение должно отменять или закрывать собственные незавершённые подключения при выходе.

`LobbyIntegration extends LobbyHooks` — необязательный локальный адаптер (общий контракт не изменён). `context()` возвращает актуальные `playerId` из welcome, `maxPlayers` из метаданных комнаты (хост знает выбранную вместимость), `credits` и `lives` из snapshot, `addresses` и `port` хоста. Без идентификатора гостя обе кнопки готовности доступны, а подтверждение нельзя приписать конкретному игроку; по тайм-ауту можно повторить действие. Без вместимости непроверенные места обозначаются как неподтверждённые. Без snapshot баланс показывается прочерком. Если хост не передал адреса, UI запрашивает `window.prismDesktop.getAddresses()` после успешного host hook. Не передавайте пароли или resumeToken в контекст.

Статусы приложения: `connected`, `reconnecting`, `resume-expired`, `host offline`, `digest mismatch`, `protocol mismatch`, `wrong password`, `room_full`, `error`. `host` и `join` должны отклонять Promise при ошибке до welcome и вызывать `update` при подтверждении; автоматическое восстановление и отсчёт времени принадлежат клиенту, не DOM. `ready/start` подтверждаются комнатой. `RunOptions.players` передаётся пустым: хост заполняет авторитетный состав. Набор технологий и знаний берётся из профиля; выбор карты фильтруется по prerequisites, режим — по requiresClear. В v1 `RoomState` не содержит вместимость гостя, а `LobbyUI` не принимает snapshot; интегратор должен подать эти данные через описанный адаптер, не изменяя формат сетевых сообщений. Модуль лобби не обещает фактический reconnect без сетевой реализации.

## Проверка

`npm run dev`, открыть `/tests/ui/lobby/preview.html`. Панель fixture показывает Create, Join, Host, Guest, Ready, Started, Mismatch, Reconnect, Expired, Offline, English, Disposed. Независимый сценарий `python tests/ui/lobby/browser_check.py` требует Python Playwright и Chromium; можно передать URL первым аргументом. Сценарий проверяет действия хуков, ошибки, fallback буфера, подтверждение старта, вывод авторитетного баланса и очистку DOM.

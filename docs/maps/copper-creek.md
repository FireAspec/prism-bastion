# Медный ручей · Карта 02

**Контракт:** v1. **Геометрия:** проверена. **Боевая проходимость:** `unverified`: на указанном базовом commit боевой движок, данные башен и каталог волн пока заглушки.

## Сюжет и доступ

Задача — освободить мастерскую лесничего. После зачёта победы должны открыться `saw` и `venom`; это делает модуль кампании, поскольку в `MapDef` нет поля выдачи награды. При первом визите разрешены ровно `needle`, `cannon`, `frost`, `beacon`, `scatter`, `ember`. Фикстуры используют только этот набор, без знаний и будущих башен.

`id=copper-creek`, `campaignIndex=2`, `difficulty=1` (только сложность геометрии), `recommendedDifficulty=easy`, `theme=garden`. В мире 1280×720 расположен один маршрут шириной 54 пикселя из 34 ненулевых сегментов: вход `(0,152)`, выход `(1280,591)`. Две петли огибают открытые сады, берег центральной заводи позволяет будущие водные постройки. Сухопутные башни покрывают обе петли без необходимости строить в воде.

Выбранная сложность, а не группа карты, определяет 40/60/80/100 волн. В `MapDef` нет поля числа волн. Явные overrides только для боссов на 10, 20, 40 с временем появления через 12/12/14 секунд и `lane:0`. Они не меняют HP босса и не начисляют вторую награду. Центральному каталогу при интеграции необходимо убедиться, что все остальные группы карты также используют её единственный lane `0`, и сохранить предупреждения о боссе.

Проверка `isBuildable` принимает целую окружность footprint, дорогу с шириной, воду, blocked-полигоны и границы мира. Вся декоративная растительность свободна от невидимых коллизий.

Вода представлена тремя полигонами; четыре blocked-полигона соответствуют мастерской, валунам, корню дерева и штабелю древесины. Векторная графика рисует все их вершины ровно по данным, без визуально сглаженного пути, не соответствующего коллизиям.

## Кандидаты replay

Исчерпывающий список шагов `beforeWave`, `tick:0`, `slot`, `tower` или индекс `path` находится в `validation/maps/copper-creek/replays.ts`. Все команды запускаются в фазе строительства, перед указанной волной. Тот же модуль экспортирует `optionsFor()` и исполняемый `executeReplay(engine,candidate)`, который использует реальный `GameEngine.dispatch/step`, возвращая `won/lost/invalid/timeout`. Ни один фикстурный план не отмечен выигрышным без такого запуска.

| Режим | Ключевые покупки | Планируемая контрмера |
|---|---|---|
| standard | W1 needle+frost; W4 cannon; W11 scatter; W14 beacon; W25 ember; W40 beacon B2 | Контроль обеих петель и резерв выхода |
| half-cash | W1 needle; W3 needle; W7 scatter; W14 frost; W25 beacon; W34 cannon; W40 beacon B2 | Экономный старт, бронепробитие и обнаружение |
| iron-oath | W1 needle+cannon; W4 frost; W8 needle; W13 beacon; W24 ember; W31 scatter; W40 beacon B2 | Независимые зоны огня при одной жизни, без продажи/доходных башен |

**Бюджет не подтверждает победу.** `estimateBudget()` учитывает только стартовые деньги и гарантированную выплату за уже завершённые волны, исключая награды за слои врагов. Стоимость улучшений пока приблизительная с условным `pathFactor=1.25`, так как башенные модули не реализованы. Использованы коэффициент цены easy 0.85 и множитель cash 0.5 для half-cash.

| Режим | Старт | Сумма за 40 волн | Минимум расчётного остатка | Остаток перед W40 после запланированных покупок |
|---|---:|---:|---:|---:|
| standard | 1000 | 8100 | 224 | 1517 |
| half-cash | 500 | 4050 | 64,5 | 214 |
| iron-oath | 1000 | 8100 | 224 | 1028 |

Проверять на настоящем движке: денежные списания; первую броню Панцирника на 10; потомство Матки на 20; щиты, теневые призывы и фактическое обнаружение фонарём B2 на 40. В strict режиме любое протекание — поражение. Перед признанием балансной победы нужны реальные прогоны всех трёх сценариев и корректировка покупок при необходимости.

## Графика и проверки

- `background.svg` — полноценный векторный фон 1280×720, видимые вход/выход, два сухих сада, ручей и мастерская. Не содержит башен и врагов из отрисовщика.
- `thumbnail.svg` — отдельная композиция 640×360 с русским названием.
- `preview.html` — автономная страница: toggles воды, пути, запретов, допустимых площадок; три разных состава и маркер движения по геометрии. Не симулирует бой.
- `validation/maps/copper-creek/background-1366x768.png`, `thumbnail-1366x768.png` — результаты визуального рендера Inkscape. HTML проверен статически; браузерную проверку следует повторить при доступности Chromium.

```sh
npm ci
node --import tsx validation/maps/copper-creek/check.ts
npx vitest run tests/maps/copper-creek.test.ts
npm run check
inkscape public/art/maps/copper-creek/background.svg --export-filename=validation/maps/copper-creek/background-1366x768.png -w 1366 -h 768
inkscape public/art/maps/copper-creek/thumbnail.svg --export-filename=validation/maps/copper-creek/thumbnail-1366x768.png -w 1366 -h 768
```

`ok:true` геометрии не является сертификатом боевой проходимости. Только центральный replay runner после интеграции может поменять `unverified` на проверенный результат.

# Солёные болота — карта 09

## Замысел

Две грузовые колонны входят с разных краёв западного острова и движутся по северной и южной дамбам. Обе дороги пересекают два приливных канала, проходят три больших острова и сливаются перед выходом на востоке. На северо-востоке видна старая насосная станция; после победы над картой открывается башня `tide` (не доступна при первом прохождении).

Карта входит в кампанию под индексом **9** (`salt-marsh`, «Солёные болота»), имеет тематическую палитру `estuary`, сложность карты **2**, рекомендуемую сложность прохождения **normal**. Предыдущие восемь карт определяют стартовый набор из 19 башен; `tide` в него не входит.

## Геометрия и тактическое пространство

- Игровое поле: **1280 × 720**. Ширина обеих дорог: **40**.
- **Две независимые входные полосы** на западе, общий узел `(1112, 361)` и один выход `(1270, 361)` на востоке.
- **Три сухопутные области**, разделённые двумя водными секторами. На пересечениях дорог с водой лежат дамбы: эти участки дороги не становятся допустимыми водными площадками.
- **Два канала** представлены многоугольниками `water`; **шесть запретных сухопутных зон** — многоугольниками `blocked`. Декоративные камыши, солончаки и насосная станция поддерживают читаемость, но не создают скрытых препятствий.
- Основное решение: ранняя защита **обоих** входов, затем перекрёстный огонь у слияния. Разделение на два маршрута исключает надёжную защиту одним ранним постом.
- Воздушные/сухопутные позиции и водные позиции имеют отдельные проверки полного посадочного места (не только центральной точки). Водные участки не превращаются в землю из-за прозрачной картинки.

Проверенные контрольные посадочные точки:

| Сухопутная точка | Координаты | Назначение |
| --- | --- | --- |
| `northApproach` | 244, 91 | Северный ранний участок |
| `southApproach` | 248, 586 | Южный ранний участок |
| `northMiddle` | 606, 110 | Северный средний остров |
| `southMiddle` | 614, 594 | Южный средний остров |
| `northConfluence` | 1065, 244 | Верхняя сторона слияния |
| `southConfluence` | 1070, 478 | Нижняя сторона слияния |
| `exitCrossfire` | 1180, 466 | Перекрёстный огонь у выхода |

Точки на воде: `westernChannel` `(420, 356)` и `easternChannel` `(861, 363)`. Они зарезервированы для водных башен при наличии соответствующего открытия. Проверка геометрии также включает запретную точку на дамбе и края каналов.

## Иллюстрации

- `public/art/maps/salt-marsh/background.svg` — оригинальный фон 1280 × 720 с обеими извилистыми акваториями, тремя островами, растительностью, контуром старого насоса и местом слияния.
- `public/art/maps/salt-marsh/thumbnail.svg` — самостоятельная иллюстрация 320 × 180 для выбора карты.
- `public/art/maps/salt-marsh/preview.html` — автономное визуальное наложение обеих дорог по координатам `MapDef`. Кнопки позволяют отдельно подсветить воду и контрольные площадки; это **не** запущенная игровая симуляция.

Дороги должны отрисовываться движком по `lanes` поверх фона. Для точной проверки их контуров предпросмотр строит линии из тех же координат; фон не подменяет препятствия или игровую логику.

## Волны и экономика

`waveOverrides` пустой: карта не фиксирует количество волн и использует общий программный набор. Для обычной кампании предусмотрено **60 волн**. Базовый расчёт дохода после волны `n` — `80 + 4n`; дополнительный доход от противников можно учитывать только после действительного уничтожения. Для `half-cash` указанные выплаты и начальный капитал сокращаются вдвое.

| Доход только за завершённые волны | Standard / Iron Oath | Half Cash |
| --- | ---: | ---: |
| Старт | 900 | 450 |
| Волны 1–20 | 2 440 | 1 220 |
| Волны 1–60 | 12 120 | 6 060 |

Таблица **не** включает средства за уничтоженные слои, доход ферм или покупки. Каждый план учитывает текущие средства в движке; будущие награды не тратятся заранее.

## Три проверяемых гипотезы прохождения

Файл `validation/maps/salt-marsh/replay-fixture.ts` содержит три воспроизводимых сценария с фиксированным seed `0x46a17`. У каждого действия есть ранняя волна, крайняя допустимая волна и нижняя граница средств; исполнитель пытается совершить действие только если хватает реальной валюты. Эти планы **пока не подтверждены победой**.

| Сценарий | Стартовые деньги | План | Ограничения |
| --- | ---: | --- | --- |
| `standard` | 900 | Отдельная защита входов, мороз/электричество в центре, яд/рельсовая башня у слияния и миномёт у выхода | Только доступные к карте башни |
| `half-cash` | 450 | Два дешёвых первых поста, контроль юга, условный `orchard`, точечные усиления у выхода | Половинные выплаты; окупаемость фермы не предполагается |
| `iron-oath` | 900 | Надёжная оборона обоих входов, затем контроль и урон у выхода | Одна жизнь, без продажи, дополнительной экономики и знаний |

**Честный статус:** `unverified` для всех трёх режимов. Текущая базовая ветка ещё не содержит полной связки боевого движка, врагов, башен и волн, поэтому никакие результаты 60-й волны, количество оставшихся жизней или победные скриншоты не заявляются. После интеграции команды ниже запустят реальные реплеи через `GameEngine`, без искусственного начисления денег, уничтожения противников или изменения жизней:

```bash
node --import tsx validation/maps/salt-marsh/replay-fixture.ts --integrated
```

Без флага инструмент перечисляет подготовленные гипотезы и явно возвращает `unverified`:

```bash
node --import tsx validation/maps/salt-marsh/replay-fixture.ts
```

## Проверки

```bash
npm run check
node --import tsx validation/maps/salt-marsh/check-geometry.ts
```

`check-geometry.ts` независимо проверяет габариты, минимальную протяжённость маршрутов, соединение, пересечения и самопересечения полигонов, сухопутные и водные площадки, дамбы и минимальное время прохождения быстрого противника. `tests/maps/salt-marsh.test.ts` дополняет его проверками содержимого, иллюстраций, точности предпросмотра, стартового ростера и структуры реплеев.

Изменения ограничены файлами карты 09, её графикой, тестами, валидацией и этой документацией. Существующие правила экономики, движок, контракты и чужие карты не изменяются.

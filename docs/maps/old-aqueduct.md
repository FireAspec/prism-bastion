# Карта 04 — Старый акведук

## Сюжет и контракт

Карта №4 кампании, группа геометрической сложности `1`, тема `garden`, рекомендация `easy` (40 волн), игровой мир 1280×720. Одна дорога проходит слева направо через две широкие арки старого водовода; пять полигонов запрещают строительство на четырёх каменных опорах и фундаменте навигационной станции. У выхода есть открытая зона для позднего перехвата.

Задача по сюжету — починить навигационную станцию. Награда за **первое прохождение**: `mortar`, `observatory`. Контракт `MapDef` не имеет полей награды и интерактивной цели, поэтому выдача этих разблокировок принадлежит `CampaignNode` соседнего модуля, который здесь не редактировался. До первой победы доступны **только** `needle,cannon,frost,beacon,scatter,ember,saw,venom,rail,tesla`. Во всех кандидатах replay используется строго этот состав даже при повторном прохождении.

| Параметр | Результат статического расчёта |
|---|---|
| Полилиния | 23 вершины, вход `(0,220)`, выход `(1280,338)` |
| Общая длина | 1399,248 px |
| Ширина | 62 px |
| Центры проходов двух арок | `(402,346)` и `(941,422)` |
| Запреты | 4 опоры арок + станция |
| Водная зона | Верхнее правое водохранилище, 12 вершин |
| Ближайшая граница препятствия/воды к оси пути | 35,77 px (половина ширины — 31 px) |
| Центры под footprint 24 на сухой сетке 40 px | 352 |
| Центры под footprint 24 в воде на сетке 40 px | 17 |
| Время простого прохода без контроля | scarlet: 26,91 c; lemon: 12,17 c; boss-carapace: 77,74 c |

Сухопутные постройки не требуют занять водную область. Водохранилище пригодно для будущих водных башен (например, `(1040,152)` и `(1131,166)`). На фоне оба выхода подписаны, путь не закрыт каменной декоративной аркой: полупрозрачные перемычки служат ориентиром, несущие опоры точно соответствуют `blocked`.

Геометрический анализатор `validation/maps/old-aqueduct/check-geometry.ts` проверяет границы, нулевые сегменты, самопересечения путей и полигонов, минимальные дистанции между дорогой и препятствиями, water/dry размещение и каждую именованную позицию. Тесты отдельно сверяют вершины полилинии с SVG и проверяют, что начальная дальность планируемых боевых башен достаёт до дороги. Footprint в изолированной проверке принят за радиус 24; реальные радиусы разных построек должен подтвердить полный каталог после интеграции.

## Площадки и стратегии

| Позиция | Координаты | Назначение |
|---|---|---|
| `westHigh` | 210,147 | Входящая дуга, иглы |
| `westLow` | 272,407 | Scatter или needle на первом изгибе |
| `archOneHigh` | 490,188 | Замедление frost у первой арки |
| `archOneLow` | 535,455 | Средний нижний огневой пост |
| `narrowsHigh` | 666,156 | Ember центрального участка |
| `narrowsLow` | 683,365 | Tesla/needle на втором участке |
| `crossingBeacon` | 772,394 | Обнаружение для башен `narrowsLow`/`archTwoLow` |
| `archTwoHigh` | 830,209 | Пушка в область второго изгиба |
| `archTwoLow` | 829,449 | Saw/Tesla по выходу из арки |
| `eastHigh` | 1028,305 | Дальняя оборона, venom или rail |
| `eastLow` | 1086,515 | Последний просторный прострел |

Две осмысленные композиции: плотная оборона первого изгиба с frost/needle/scatter и последним перехватом; либо распределённая восточная с cannon, tesla, rail и раскрытием скрытности. Каменные опоры исключают «универсальную» точку прямо на дороге. Все площадки — лишь ориентиры; остальные свободные участки суши доступны на общих правилах.

`waveOverrides={}` — намеренно. Карта не меняет выплаты, здоровье боссов или общее количество волн. Выбранная сложность даёт 40/60/80/100 волн, независимо от группы карты. Конечные боссы общей программы на 10/20/40 волнах: Панцирник, Матка осколков, Зеркальный регент. Специфические ответы с доступными при первом прибытии технологиями:

- Скоростные amber/lemon: ранний needle + frost; у поворота scatter.
- Iron, босс Панцирник (10): needle ветки B и cannon ветки C, затем rail ветки A.
- Щиты, волны 11–19: tesla ветки B, venom ветки B.
- Cloak, волны 11–19 и призывы босса 40: beacon ветки B до первого скрытого врага.
- Многочисленные потомки Матки (20): scatter ветки A, cannon ветки A, ember ветки C.
- Регент (40): rail A для босса, tesla B для щита, beacon B для скрытых, резерв у выхода.

## Честные воспроизводимые кандидаты

Полные списки `волна/тик/позиция/покупка` находятся в исполняемой TypeScript-фикстуре `validation/maps/old-aqueduct/replay-fixture.ts` (`candidates[]`, действия `place` и `upgrade`, привязки ID купленных башен через `alias`). Все действия запланированы на `tick=0` до старта названной волны; seed фиксирован; знания `[]`; никаких скрытых кредитов, предсозданных башен, принудительной гибели врагов или изменения волн. Единственным источником результатов служит реальный `GameEngine`, когда он будет доступен.

| Режим | Seed | Покупки волны 1, тик 0 | Стартовый расход/остаток |
|---|---:|---|---:|
| `standard` | 410401 | needle `(210,147)`, scatter `(272,407)`, needle `(535,455)` | 788 / 212 из 1000 |
| `half-cash` | 410402 | needle `(210,147)`, needle `(272,407)` | 426 / 74 из 500 |
| `iron-oath` | 410403 | needle `(210,147)`, frost `(490,188)`, scatter `(272,407)` | 1000 / 0 из 1000 |

Цены здесь — easy `ceil(base × 0.85)`, без знаний. Half-cash уменьшает стартовые деньги/доход, не цены башен. Iron-oath оставляет одну жизнь и запрещает продажи, знания и пассивный фарм. Именованные планы намеренно используют разные композиции, включая контроль центра и восточный перехват.

Контрольный **нижний предел** бюджета без дохода за снятие слоёв и без промежуточных улучшений:

| Сценарий | Ключевой момент | Математика |
|---|---|---|
| Standard | Frost за 425 перед волной 4 | 212 + 105 + 110 + 115 = 542; остаток 117 |
| Standard | Cannon за 468 перед волной 8 | 117 + 120 + 125 + 130 + 135 = 627, нужно учесть улучшение игл на волне 6 |
| Half-cash | Cannon за 468 перед волной 8 | 74 + (105 + 110 + 115 + 120 + 125 + 130 + 135) / 2 = 494; остаток 26 |
| Half-cash | Beacon за 510 перед волной 11 | Около 243 кредитов из гарантированного дохода, требуется минимум ещё ~267 кредитов от слоёв и стоимость улучшений |
| Iron-oath | Needle за 213 перед волной 3 | 105 + 110 = 215; остаток 2 |
| Iron-oath | Cannon за 468 перед волной 7 | 2 + 115 + 120 + 125 + 130 = 492; остаток 24 |

Выше приведён расчёт доступных средств, **не доказательство прохождения**. Поздние высокие тиры могут оказаться слишком дорогими, другие типы врагов — слишком многочисленными. Каждое отклонённое действие, отрицательный бюджет, поражение, нарушение требуемого числа жизней или волна дольше 600 игровых секунд приводит к `failed` без подмены результата.

У всех трёх планов **`verification:'unverified'`**. Реальный симулятор в исходном коммите — заглушка. После слияния центральный тест создаёт конфигурацию по `mapId='old-aqueduct'`, difficulty/mode/seed/knowledge/unlockedTowers фикстуры и вызывает `executeCandidate(engine,candidate)`. Только фактическая победа после 40 волн и соблюдение `minimumLives` дают отчёт `verified` с `lives`, `credits`, `totalTicks`, фактической ценой покупок. Особенно важно тестировать в целой игре `half-cash` и `iron-oath`, а не объявлять их проходимыми по статическому DPS.

## Ресурсы и проверка

- `public/art/maps/old-aqueduct/background.svg` — фон 1280×720, масштабируемый вектор, без CDN.
- `public/art/maps/old-aqueduct/thumbnail.svg` — самостоятельная отдельная миниатюра 640×360.
- `public/art/maps/old-aqueduct/preview.html` — автономный просмотр, переключатели арта/границ/маршрута/двух оборонительных раскладок. Игровой canvas renderer этот файл не использует.

```sh
node --import tsx validation/maps/old-aqueduct/check-geometry.ts
npm run typecheck
npm test -- --reporter=verbose
npm run check
inkscape public/art/maps/old-aqueduct/background.svg --export-type=png --export-width=1366 --export-height=768 --export-filename=/tmp/old-aqueduct-background-1366.png
inkscape public/art/maps/old-aqueduct/thumbnail.svg --export-type=png --export-width=1366 --export-height=768 --export-filename=/tmp/old-aqueduct-thumbnail-1366.png
```

Точки и полигоны проверяются исполнением реального геометрического анализатора; fake engine в тесте нужен лишь для проверки, что неуспешная покупка **никогда** не объявляется победой. Тесты не используют реализацию смежных незавершённых модулей.

Ограничения интеграции: контракт карты не описывает сюжетное действие и награду кампании; `src/content/index.ts`, программа волн, engine и боевые башни в базовом коммите могут ещё быть незавершёнными. Нельзя утверждать, что вся игра готова, или что предложенные стратегии уже проверены в бою.

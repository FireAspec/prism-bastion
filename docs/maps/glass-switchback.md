# Карта 15 — Стеклянный серпантин

**ID:** `glass-switchback` · **Сюжет:** 15/20 · **Сложность карты:** 3 · **Рекомендация:** hard, 80 волн · **Мир:** 1280 × 720.

## Замысел

Заброшенный стеклянный перевал между приливными чашами. Дорога сперва идёт вправо, затем четырежды меняет горизонтальное направление и уходит к правому выходу. На сухих уступах можно устроить перекрёстный огонь, в четырёх водных карманах — разместить водные постройки. Скалы, обсервационные обломки и вода — настоящие запретные области строительства.

После победы открывается **минный узел** (`mine`); он не входит в стартовый ростер и не нужен для первого прохождения. `waveOverrides` оставлен пустым: карта обязана использовать общий канонический порядок волн без локальной подмены вознаграждений.

## План по волнам (кандидаты, не проверенные победы)

Подготовлены три сценария `validation/maps/glass-switchback/replay-candidates.json`. Каждый содержит `status: "unverified"`, фиксированный seed `521501`, порядок строительства и апгрейдов до 80-й волны, никакого добавления валюты или жизни. Реальные траты после первой волны следует подтверждать движком; задуманный тайминг может потребовать корректировки.

| Режим | Первый ход (до волны 1) | Начальный остаток | Принцип |
| --- | --- | ---: | --- |
| standard | Игломёт 275 + страж 468 | 107 из 850 | оборона → мороз → обнаружение → ограниченная экономика → антипанцирь / боссы |
| half-cash | Игломёт 275 | 150 из 425 | нет ранней фермы, все покупки после фактического поступления половинных доходов |
| iron-oath | Игломёт 275 + страж 468 | 107 из 850 | одна жизнь, ранний резерв; никаких ферм, процентного дохода, знаний или продажи |

Цены первых покупок отражают коэффициент hard ×1,10 с целым округлением. `mine` исключён из списка 25 ранее доступных башен. Следующие ключевые противодействия: `observatory` для скрытных, `venom` и `rail` для брони, `tesla` для щитов, `frost` для быстрого потока, `mortar` / `rocket` / `prism` для крупных групп и боссов. В iron-oath пассивная экономика запрещена; в half-cash недопустимо округлять доход вверх или вручную увеличивать бюджет.

## Проверки

Из корня репозитория:

```sh
node --import tsx validation/maps/glass-switchback/analyze.ts
npm run check
```

Анализатор проверяет размеры, вырождения и пересечения многоугольников, дорожный коридор, окружности наземного и водного строительства, 10 опорных площадок и 42 запланированных действия. Тесты дополнительно сверяют JSON-карту предпросмотра и базовый бюджет всех режимов, а также гарантируют, что отказ игрового API не засчитывается за победу.

### Граница подтверждения

На исходном коммите `65ae156626cab219a9d8a6e7e6a63f8b4663d1f7` функция `src/engine/index.ts:createGame` выбрасывает `Simulation module pending`; контент башен, сложности, режимы и волны также содержат заглушки. Поэтому на текущей базе **нельзя запустить честную 80-волновую симуляцию и подтвердить победы**. Файл `replay.ts` даёт адаптер, который принимает настоящий `GameEngine`, исполняет команды с проверкой фактических средств, статуса команд, 1/60-секундных тиков и результата всех 80 волн. Он намеренно не симулирует доход, урон, награды или здоровье своими формулами. После появления соответствующих модулей необходимо выполнить все три сценария и откалибровать стратегии по настоящим результатам.

Также требуется ручной контроль визуального отображения в конечном клиенте игры. SVG и HTML являются самостоятельными локальными активами и не используют сетевые ресурсы.

## Границы изменений

Этот пакет затрагивает только карту `glass-switchback`, её локальный арт, тест, анализатор, кандидаты повторного прохождения и настоящую документацию. Центральные контракты, игровые правила, реестр карт, другие карты и волновой баланс не меняются, поскольку они принадлежат другим задачам.

# Грузовой двор — карта 06

## Контент и смысл

- `id=freight-yard`, позиция кампании 6, группа геометрии 2/4, тема `foundry`.
- Рекомендуемый отдельный уровень сложности — **normal**. Число волн устанавливает выбранная difficulty: easy 40, normal 60, hard 80, extreme 100. Группа карты не определяет число волн.
- Задача — вернуть транспортный ангар. После **первой победы** сюжетный `CampaignNode` должен открыть `drone`, `rocket`. Эти башни не входят в набор первой попытки. `MapDef` по контракту не содержит поле `unlocks`; менять модуль кампании из карты запрещено, поэтому интегратор должен указать соответствующий `CampaignNode.unlocks` там.
- Первый доступный набор: `needle,cannon,frost,beacon,scatter,ember,saw,venom,rail,tesla,mortar,observatory,mint,orchard`.

## Геометрия

Мир 1280×720, диаметр полосы 52 px. Западная линия A начинается в `(0,164)`, южная B — в `(941,720)`. Их общая заключительная часть — `(1070,380) → (1176,380) → (1280,380)`; видимые выходные ворота справа, телепорта нет. Конкретные промежуточные точки записаны как два массива `MapDef.lanes`.

| Маршрут | Длина | Время без статусов при 132 px/с | При 18 px/с |
|---|---:|---:|---:|
| Западный A | 1476 px | 11,2 с | 82,0 с |
| Южный B | 1865 px | 14,1 с | 103,6 с |

Это только нижняя аналитическая оценка реакции для указанных скоростей (без режимных множителей и боевых эффектов). Южная петля компенсирует позднее включение нижнего входа. На волне 1 впереди A, на волне 2 — B, с волны 3 группы чередуются по объявленному времени появления. Overrides 1–9 задают только `groups/preview`; награды и боссы остаются в общем наборе волн, без двойных начислений.

### Размещение

Анализатор проверяет консервативный корпус радиусом 28 px и дополнительно 8 px между ним и дорогой, водоёмом, запретной зоной или краем. Фактический `TowerDef.footprint` должен дополнительно проверяться движком при интеграционном replay.

Пять `blocked` полигонов совпадают с нарисованными корпусами цехов, складом, резервуарами и фундаментом. Два `water` полигона — охлаждающие бассейны; будущие водные башни радиусом 28 px могут стоять в `(90,595)`, `(165,623)`, `(1124,609)`, `(1196,638)`. Они не перекрывают обязательные сухие посадки и не требуются при первом заходе.

Две существенно разные стратегии размещения:

1. **Центральный узел:** C1 needle, C2 scatter, E1 frost, S1 beacon, N1 rail. Ранний двойной охват путей, но нужна защита начального западного участка.
2. **Разнесённые рубежи:** W1 needle, W3 tesla, B2 mortar, N1 rail, E1 frost. Лучше распределяет огонь по входам, но менее эффективно держит одновременный рывок к общему выходу.

Даже если кассовый разрыв погашен, наличие достаточного DPS и победа остаются недоказанными. Провал отдельного расписания также не доказывает непроходимость карты.

## Инструменты проверки

```bash
node --import tsx validation/maps/freight-yard/geometry-check.ts
node --import tsx validation/maps/freight-yard/replay.ts --static
npm run check
```

Проверяется: мир и все полигоны в границах, отсутствие нулевых сегментов и самоперекрытия, минимальный зазор до дороги и препятствий, 13 сухих позиций, девять одновременно размещаемых башен, четыре водных места, время движения, чередование ранних волн, три легальных набора покупок и приблизительная бюджетная ведомость. Статический аудит выводит `static-pass-replay-unverified`.

Реальный runner для поздней интеграции:

```bash
node --import tsx validation/maps/freight-yard/replay.ts --simulate standard
node --import tsx validation/maps/freight-yard/replay.ts --simulate half-cash
node --import tsx validation/maps/freight-yard/replay.ts --simulate iron-oath
```

Он вызывает настоящий `loadContent()`, `createCombat()`, `createGame()`, делает покупки только через `dispatch`, проходит каждую волну фиксированными тиками 1/60, не вводит искусственную валюту, требует `victory`, учитывает фактические жизни и кредиты. При исходных заглушках движка/каталога/боя возвращает `status:unverified`, код `2`. Только после реальной победы можно считать replay проверенным. Нельзя заменять replay расчётом DPS или заглушкой.

## Арт и передача интегратору

`background.svg` — собственный мир 1280×720; `thumbnail.svg` — независимая миниатюра 640×360; `preview.html` позволяет локально переключать пути, площадку и посадки. Фон рисует только неподвижную подложку и не владеет противниками, интерактивными башнями или hitboxes — они принадлежат Canvas и `MapDef`. Игре не требуется сеть/CDN.

Интегратор должен включить карту в общий контент-реестр, дать ей unlocks `[drone,rocket]` **после** победы и проверить соответствие фактических `TowerDef.footprint` и tier-факторов. Программа волн 10–100 должна маршрутизировать объявления по lane 0/1, не менять боссов скрыто и позволять контрприёмы всеми доступными на первом визите башнями. До полноценного движка боевая проходимость и экономический баланс остаются открытыми проверками.

# Искусство маяка

Вертикальная доктрина `lighthouse`, контракт v1. ID `lighthouse-01` … `lighthouse-30` сохраняются в профиле. `getKnowledge()` возвращает независимые объекты, включая вложенные массивы. Все проценты аддитивны; `lives` — абсолютное число. Каждый узел требует предыдущий, кроме первого.

## Интеграция

Данные не содержат движка или функций поведения. Сервис progression применяет эффекты ровно один раз к исходным определениям; режим iron-oath исключает все узлы, а при maxLives=1 (extreme, no-leaks, iron-oath) бонус жизней исключается. XP/печати обрабатывает только сервис наград; продажи и боевые кредиты не меняются. При кооперативе повторяющиеся ID объединяются как множество. Эти правила проверяются на уровне интеграции с модулем 80.

Все 30 SVG автономны, 64×64, с индивидуальным силуэтом и текстовым title. Шести рубежам соответствует шестигранная рамка. Пути icon — URL относительно корня Vite public.

## Проверки

`npm test -- tests/knowledge/lighthouse.test.ts` — структура, бюджет, предельный вклад каждого ранга, независимость выдаваемых данных, существование и уникальность иконок. Проверка фактических атак, режимов и наград требует реализации progression.

Локальная проверка: TypeScript 5.8.3, strict, noEmit, ES2022, Bundler, полный встроенный контракт v1 — успешно. Шесть тестов выполнены в Node 22.16.0 через адаптер регистрации `test` (используется `node:test`, не Vitest); 6/6. Все 30 SVG растеризованы CairoSVG и собраны в лист просмотра. Общий `npm run check` недоступен в изолированной среде без полного checkout и зависимостей; это не подтверждение общей сборки. Реальные изменения боевых параметров и режимов требуют модуля progression.

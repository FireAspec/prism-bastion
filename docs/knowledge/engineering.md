# Инженерия

Контракт v1: getKnowledge(): KnowledgeNode[]. ID engineering-01…engineering-30 неизменяемы. Каждый вызов возвращает независимый массив. Иконки — локальные SVG, путь от корня сайта.

## Правила

30 узлов, каждый требует предыдущий, одно очко, цена печатей ceil((20+5n+n²/3)/5)×5. Уровни блоков: 1, 5, 9, 13, 17, 21. Рубежи 5/10/15/20/25/30 объединяют разные эффекты. Минимальный уровень последнего узла не гарантирует наличие всех очков и печатей.

supportRadius изменяет только радиус существующей ауры; revealRadius — только обнаруживающей ауры. Для неё оба множителя учитываются сервисом прогрессии согласно общим правилам. abilityCooldown — положительная доля сокращения времени, а не отрицательная длительность; без способности бонус не действует. purchaseDiscount глобальна, поскольку v1 хранит её одним числом в GameConfig.knowledgeDiscount. Не применять к продаже, не менять lives. Сервис 80 обязан отключать знания в iron-oath и объединять кооперативные ID без повторов; no-actives запрещает применение способностей.

Бюджет на одну башню: S=12%, C=12%, R=7% (из общего 15%), D=4% (из общего 8%). Скидка с аурами не выше 20%; возврат floor(0.7×invested). Нет новых stat, урона или скорости атаки.

## Проверки

`npx vitest run tests/knowledge/engineering.test.ts` — структура, бюджет по каждой башне и на каждом префиксе, контрольные эффекты, независимые копии и ресурсы. Тесты не вызывают незавершённый сервис прогрессии. Сквозное применение к базовым данным и аурам/способностям улучшений, блокировка режимов, покупки и сохранения требуют интеграции модулей 80 и 01.

# Штормовой шпиль — `storm`

Элементальная наземная башня (`element`, `land`, footprint 26). Вход: `getTower():TowerDef`, возвращающий независимый объект данных согласно frozen v1 API.

Базовая цена 1100 кредитов, электрический урон 22, интервал 1,2 с, дальность 200 пкс, `chain` с одним переходом в 96 пкс. Базовый DPS первой цели ≈18,33 без брони, сопротивлений и щита. При продаже действует общий `floor(0.70 × invested)`, башня не меняет возврат и не создаёт доход.

## Правила синергий и ограничения

- Намокание `wet` на цели даёт +20% электрического урона по общему v1 combat-правилу; первый удар с наложением намокания не обязан получать бонус сам. Статус не суммируется до бесконечности (maxStacks=1).
- `ring` и `pulse` — периодические локальные атаки, не урон по кадрам. `push` уважает единые лимиты отталкивания противников и боссов.
- Ветка B усиливает боссов, щиты, бронепробитие; режим `strong` для приоритетной сильной цели выбирает сам игрок. В `AttackDef` отсутствует автоматическое наведение «по самому сильному»; эта механика не заявляется.
- `chainsAdd` не превращает `ring`/`pulse` в цепь. Кросс B2 остаётся полезным им благодаря бронепробитию, общему урону, щитам и боссам.
- Сильнейшее `replaceAttack` выбирается только из ведущей ветки T3+; T1/T2 не заменяют режим атаки. Эффекты одного ID заменяют более ранние; echo ограничен cap и interval.
- Вся экономика — 0 кредитов с атаки/раунда; отсутствуют доход, interest, скидки, самоускоряющиеся ауры, рекурсивное copy.

## Изображения

В `public/art/towers/storm/` имеются 16 самостоятельных прозрачных SVG 128×128: `base.svg`, `a1..a5.svg`, `b1..b5.svg`, `c1..c5.svg` и шесть наложений `a1/a2/b1/b2/c1/c2-overlay.svg`. У всех pivot 64,64, нет внешних скриптов, изображений или шрифтов. `preview.html` показывает базу, 15 ступеней и все шесть сочетаний 5–2–0. T1/T2 добавляют геометрию, T5 урагана — многоярусная воронка, T5 грома — высокая золотая игла, T5 ливня — облачный зонт с дождём.

При сборке renderer берёт ведущую модель `ResolvedTower.visual.asset`, поверх накладывает `secondaryOverlay` вторичной ветки нужного тира. Размер спрайта T5 не меняет игровую footprint.

## Проверки и интеграция

`tests/towers/storm.test.ts` проверяет три ветки по пять уровней, стоимость, уникальность ID, конечность параметров, ограничения эффектов, матрицу допустимых `tiers`, шесть вариантов кросс-пути и 22 локальных SVG. Используется изолированный fixture-resolver на frozen API: в базовом коммите combat пока заглушка. Интегратор после слияния должен проверить расчёт статусов, применение `wet + electric`, echo на периодических атаках, boss-control и сетевую синхронизацию. Полноценный бой, кампанию и кооператив нельзя объявлять проверенными по данным модуля.

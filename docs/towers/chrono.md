# Хронобашня / Chrono Tower

## Назначение и комплект

`chrono` — технологическая наземная постройка, открываемая после карты «Часовая площадь». Базовая цена 1 000 кредитов, размер установки 26, энергетический выстрел на 3 урона раз в 1,2 секунды, дальность 165. Начальный прямой DPS: **2,5**. Башня не создаёт кредиты и не восстанавливает жизни.

В поставке:

- `src/content/towers/chrono.ts` — чистая `getTower(): TowerDef`, которая каждый раз возвращает независимое дерево данных.
- `public/art/towers/chrono/base.svg`, `a1.svg`…`c5.svg` — 16 полноразмерных векторных моделей 128×128, точка опоры 64,64, прозрачность.
- `a1-overlay.svg`, `a2-overlay.svg`, `b1-overlay.svg`, `b2-overlay.svg`, `c1-overlay.svg`, `c2-overlay.svg` — 6 прозрачных накладок вторичной ветки, не перекрывающих основу.
- `preview.html` — просмотр исходной модели, всех 15 последовательных форм, накладок и шести финальных комбинаций 5–2–0; `contact-sheet.png` — растровый обзор для проверки и обсуждения.
- `tests/towers/chrono.test.ts` — проверки контрактных данных, всех легальных уровней через локальный резолвер и ресурсов.

Идентификаторы веток `chrono-a`, `chrono-b`, `chrono-c` и улучшений `chrono-a1`…`chrono-c5` постоянны. Все стоимости — **стоимости отдельных покупок на normal**, до коэффициента сложности и скидок.

## Расчётная эффективность

Столбец «прямой DPS» — урон **одной основной цели без брони/щита, сопротивлений, бонусов других башен и цепных переходов**. Для splash/ring значение относится к одному противнику внутри поражаемой области. Для B5 два прямых снаряда считаются как два попадания при достаточном числе целей; на единственной цели движок может распределить их иначе. Echo A5, вторичные цели, mark, бонусы по боссам, движение и активные умения в DPS не включены. Это не подтверждение проходимости карты.

## Правила синергии и против бесконечного контроля

1. `a1` прикладывает один `slow` на источник; заменяющая атака A3–A5 несёт более мощное замедление. Статусы одного kind/источника объединяются без суммирования длительностей. Действует нижняя граница скорости врага 25% исходной. Боссов ограничивает `controlFactor`, поэтому 55% замедления не превращается в остановку босса.
2. `b1` умножает интервал, `b2` умножает урон; `b3`–`b5` оставляют `chrono-tempo` с одним и тем же ID. Повышения ауры **заменяют** прежнюю версию, а не складываются. Источник не получает собственную ауру; другие темповые ауры конкурируют по максимальному значению, общий эффект ≤50%. Скорость атак не изменяет силу или радиус ауры; соседние источники могут получать чужую ауру, но без рекурсивного роста её параметров.
3. `c1` накладывает mark (+10% входящего урона на 1,8 с), а не push: обычные попадания не расходуют общую личную защиту от возврата. `chrono-reversal` обновляется по одному ID, с интервалом 7 / 6 / 4,8 c и общим для всех источников личным cooldown врага; за цикл выбирается один доступный противник; активный `chrono-rewind` также обновляется по одному ID. Все перемещения только назад по текущему маршруту, с отсечением у начала пути. Награда за снятые слои не начисляется повторно.
4. Автоматический `portal` и активный `rewind` не расходуют валюту и не генерируют доход; количество способностей и рефанд не увеличиваются. Продажа — **floor(0,70 × фактически вложенные кредиты)** независимо от веток. При отключённых способностях C4/C5 сохраняют основную пассивную петлю.
5. В строгом режиме со 1 жизнью башня не даёт восстановления. Отсутствуют `interest`, `harvest` и любая экономическая аура. Способности могут быть запрещены модификатором режима; автоматический контроль и обычные атаки остаются данными башни.

## Визуальные сигналы

- A — янтарный треснувший циферблат, разлетающиеся стрелки и падающие песчинки; T5 заменяет целые часы разрозненными сегментами с сияющей трещиной.
- B — бирюзовые вращающиеся венцы, пружины и быстрые штрихи; T5 вместо привычного циферблата показывает кристаллическое ядро в трёх орбитах.
- C — фиолетовое стекло песочных часов, стрелки возврата и песок, идущий вверх; T5 — увеличенные часы с обрамляющими дугами обратного движения.

Финальная накладка всегда берётся из вторичной ветки (`a2-overlay.svg`/`b2-overlay.svg`/`c2-overlay.svg`) и не подменяет главное полноразмерное изображение. Геометрия имеет прозрачные поля и не меняет игровой `footprint: 26`. Локальные CSS-анимации SVG отключаются через `prefers-reduced-motion`; игровая анимация `VisualState.motion` также управляется системой рендера. Встроенный CSS не обращается к сети.

## Проверка и интеграция

Из корня репозитория:

```sh
npm ci
npm run check
```

Локальная приёмка охватывает параметры и все разрешённые комбинации `[A,B,C]` 0..5, шесть комбинаций 5–2–0, эффекты, уникальность ID, копирование данных, существование SVG/preview. Дополнительно 28 ячеек контактного листа (16 полных моделей, 6 накладок и 6 сочетаний) были реально отрендерены через CairoSVG и просмотрены. Исходные XML/SVG файлы успешно разобраны; отсутствие обрезания оценено на контактном листе.

**Сверка с боевой веткой:** `feature/02-combat`, commit `dcbc5f47ee3b969af0136f3358b612f2b92c8087`: `resolve.ts`, `attack.ts`, `damage.ts`, `movement.ts`. `pulse` в этой реализации центрируется на башне, поэтому A3–A5 используют летящий splash с фактическим контактом; C5 — ring с `splash=0`, радиус равен итоговой дальности, без пустой зоны между дальностью и областью урона. Эхо создаётся один раз на атаку, задержка `interval + windup`, цепь начинается в прежней позиции цели; попадание зависит от наличия целей. Обычный push, портал и активный откат делят `combat:rewindUntil`; C1 заменён на mark, чтобы не расходовать этот cooldown на слабое отталкивание. Пассивный портал перемещает одну доступную цель за цикл, активный — всех доступных в радиусе. Для боссов применяются уменьшенный сдвиг и более длительная личная защита.

**Граница проверки:** локальный fixture resolver следует контракту и проверяет все 64 легальные комбинации; это не исполнение настоящего `combat.step`. Базовый main содержит заглушку боевого модуля; исходники ветки №02 сверены, но полноценный игровой прогон, replay, сохранение cooldown и общий баланс необходимо подтвердить на интеграционной сборке. В контракте нет необходимости менять типы.


При повторной локальной проверке: `tsc --strict --noEmit` — без ошибок; 10 сценариев с исходными Vitest-утверждениями выполнены через временный адаптер Node `node:test` — 10/10. Адаптер в проект не входит. Повторный штатный `npm run check` не запускался: из текущего окружения недоступно клонирование репозитория и установка зависимостей. 22 SVG разобраны и растрированы при 256×256; прозрачные поля сохранены со всех сторон, обновлённый контактный лист на 28 форм просмотрен.

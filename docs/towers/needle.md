# Игломёт — игровое содержимое и интеграция

`needle` — доступная с первой карты наземная башня категории `weapon`.
Источник: `src/content/towers/needle.ts`, экспорт `getTower(): TowerDef`.
Контракт v1; возврат **новой глубокой копии** на каждом вызове.

## Основные параметры и стоимость

| Параметр | Значение |
|---|---:|
| Покупка | 250 кр. |
| Урон / элемент | 8 / kinetic |
| Интервал | 0,55 с |
| Дальность | 160 px |
| Скорость / радиус снаряда | 760 px/с / 2 px |
| Footprint | 26 px |
| Базовый урон/с по одиночной цели без защиты | 14,55 |

Цена **каждой** ступени на любой ветке — соответственно 125, 250, 625,
1 500 и 3 750 кредитов. Полная основная ветка с башней — 6 500 кр.;
финальный кросс-путь `5–2–0` — 6 875 кр. Реальные покупки учитывают
множители режима и скидки, возврат продажи — `floor(0.70 * invested)`:
без скидок за `5–2–0` возвращается 4 812 кр., то есть потеря 2 063 кр.

## Ветки, этапы и точные игровые эффекты

Во всех таблицах `×` — множитель к соответствующему параметру **на данной
ступени**, `+` — аддитивный бонус. Применяются все предыдущие ступени.

### A — Швейная буря

| Тир | Название | Эффект |
|---:|---|---|
| 1 | Подшипники ветра | Интервал ×0,90; скорость снаряда ×1,15 |
| 2 | Двойная шпулька | +1 независимая игла в залпе |
| 3 | Вихревая катушка | Интервал ×0,80; `focus` +0,08 урона/с по одной непрерывно обстреливаемой цели, cap +0,35 |
| 4 | Тройной барабан | +1 игла, интервал ×0,70; тот же `focus` заменён на +0,12/с, cap +0,60 |
| 5 | Пять колец урагана | +2 иглы (суммарно 5), интервал ×0,60; `focus` +0,20/с, cap +1,00; пять видимых роторов |

Интервал финальной A: `0.55 × 0.9 × 0.8 × 0.7 × 0.6 = 0.16632 с`.
Урон/с до фокуса 240,50; максимум фокуса через пять секунд удержания
одной цели — 481,00 (до сопротивлений, брони и смены цели).

**Ограничение DSL:** контракт не содержит эффекта, который динамически
уменьшает интервал при непрерывном огне. Реализована постоянная ускоренная
стрельба и растущий при удержании цели `focus`: это нарастающий **эффективный
урон**, а не обещание изменяющейся в ходе боя частоты. Подмена формата
состояния или самостоятельный боевой таймер ради анимации не используется.
Динамическое ускорение выстрелов можно рассмотреть в следующей версии
контракта; нынешняя ветка работает без него.

### B — Алмазные иглы

| Тир | Название | Эффект |
|---:|---|---|
| 1 | Карбидный сердечник | +2 игнорируемой брони |
| 2 | Сквозная закалка | Урон ×1,20; +1 пробиваемая цель |
| 3 | Гранёный пробойник | +3 пробития брони, +2 цели, скорость снаряда ×1,20 |
| 4 | Осадная огранка | Урон ×1,50; +2 цели; урон по щитам ×1,20 |
| 5 | Сердце алмазного копья | Атака меняется с `shot` на `beam`: до дельт 24 урона / 0,50 с / 180 px; ещё +4 цели, урон ×1,50, урон по щитам ×1,25, по боссам ×1,20 |

Финальная B: мгновенный серебряный луч, 64,8 урона за контакт,
129,6 урона/с по единственной цели, 10 разных целей в линии,
5 игнорируемой брони, щиты ×1,50, боссы ×1,20.
Десять целей — максимум **контактов**, а не десятикратный урон одиночному
противнику. Площадное поражение отсутствует: важна геометрия линии.

### C — Рикошетный рой

| Тир | Название | Эффект |
|---:|---|---|
| 1 | Дальний челнок | Дальность ×1,18 |
| 2 | Точно в уязвимость | Урон ×1,25; урон по боссам ×1,15 |
| 3 | Первый зигзаг | Атака меняется с `shot` на `chain`; +2 перехода, радиус перехода 80, урон ×1,10 |
| 4 | Перекрёстные стежки | +1 независимая цепь; +2 перехода; радиус +25; интервал ×0,90; `mark` +10% входящего урона на 2,5 с (1 стек) |
| 5 | Золотая корона роя | Новая тройная цепь с исходными 14 урона / 0,55 с / 180 px, ещё +1 цепь, +4 перехода, радиус +30, урон ×1,80, интервал ×0,75 |

Финальная C: три независимые цепи, до восьми дополнительных переходов
каждой, радиус очередного перехода 135 px, 34,65 урона на контакт,
интервал 0,37125 с. Чистый DPS первых попаданий при трёх доступных
целях — 280,0; верхний предел за залп — 27 **разных контактов по цепям**,
но это не гарантия наличия целей и не сумма урона по одному противнику.
Повторная цель в рамках одного обхода не должна создавать бесконечные
переходы; данный порядок обеспечивает интегрирующий combat.

## Численная сравнительная таблица

Урон/с — теоретический урон первых контактов при наличии нужного числа
целей, **до брони, сопротивлений, статусов, перелёта снаряда**. Для A после
тир 3 диапазон показывает нулевой и максимальный `focus`. Для B число в
столбце «цели» означает глубину прострела; для C — возможные переходы
**одной цепи**, не считая первого контакта. Фактический DPS на карте

## Шесть финальных кросс-путей

| Основная / вторичная | Итоговая атака | Существенная выгода вторичной |
|---|---|---|
| A5 + B2 | `shot`, 5 игл | Урон ×1,20, +2 пробития брони, +1 сквозная цель |
| A5 + C2 | `shot`, 5 игл | Урон ×1,25, дальность ×1,18, боссы ×1,15 |
| B5 + A2 | `beam`, 2 луча | Интервал ×0,90, независимый второй луч |
| B5 + C2 | `beam` | Урон ×1,25, дальность ×1,18, боссы ×1,15 |
| C5 + A2 | `chain`, 4 цепи | Интервал ×0,90, независимый четвёртый канал |
| C5 + B2 | `chain`, 3 цепи | Урон ×1,20, +2 пробития брони, +1 прямое пробитие |

Высший `replaceAttack` берётся только у основной ветки; T1/T2 никогда
не заменяют режим атаки. Затем суммируются/умножаются все дельты A→B→C.
Термин «пробитие» относится к полю `pierce` прямого контакта; если цепная
атака реализована без линейного участка, её важнейший бонус от B2 — урон
и бронепробитие, а не дополнительные переходы (они определяются `chains`).
Эффекты с одинаковым ID заменяют предыдущую силу фокуса, не складываются.

## Ресурсы и визуальная интеграция

- Папка `public/art/towers/needle/`: `base.svg`, `a1..a5.svg`, `b1..b5.svg`,
  `c1..c5.svg` (16 полных моделей), `a1-overlay.svg`, `a2-overlay.svg` и
  аналогичные для B/C (6 прозрачных накладок).
- `preview.html` показывает все модели и все **шесть** полных сочетаний:
  основная T5 плюс вторичная накладка T2. Ресурсы без сетевых зависимостей;
  SVG прозрачные, 128×128, центр относительно `(64,64)`.
- A5: пять кольцевых роторов, множество игл и пунктирные трассы.
  B5: массивный многогранный наконечник, светлые пробойные трассы.
  C5: три золотых челнока и ломаные рикошетные линии.
- Renderer получает `visual.asset` основной ветки и отдельно
  `secondaryOverlay` из resolver. `muzzle`, `projectile`, `impact` имеют
  собственные ключи `needle-*` для согласованного показа трасс; визуальные
  события не начисляют урон.
- Ключи `motion`: A=`rotate`, B=`breathe`, C=`orbit`; `reducedMotion`
  должен отключать активное движение через общий renderer, не через SVG.
  Следует показывать полные картинки даже в `low quality`, уменьшая
  частицы, но не игровую частоту атаки.

## Проверка и границы ответственности

Локальный `tests/towers/needle.test.ts` проверяет типы, 15 ID, цены,
конечность эффектов, все 216 состояний tiers с фильтрацией легальности,
все шесть T5-кросс-путей, независимые копии, боевые характеристики,
существование 22 ресурсов и локальность `preview.html`. Resolver теста —
небольшая независимая fixture-реализация правил контракта, **не** замена
боевому модулю. Только интеграционный бой может подтвердить реальную
частоту попаданий, прохождение волн и экономический баланс.

Заявленные ориентиры — начальная балансная гипотеза. Проверка карт и
общего DPS против щитов, брони, скоростей врагов и боссов выполняется
после интеграции combat, enemies и waves. До этого не утверждается
успешное прохождение всех карт или полная интеграция игры.

## Ресурсы и совместимость

16 полноразмерных SVG и 6 накладок с суффиксом -overlay.svg. Холст 128×128 с прозрачным фоном, pivot 64,64. Исходная геометрия масштабирована с 160×160, все элементы встроенные. Три басовых мембраны, ломаная корона, два высоких золотых камертона. preview.html показывает все 16 основных моделей и все 6 сочетаний; есть переключатель на компактный масштаб поля. Отдельные visual keys для каждой ступени. Каталог получает новую независимую копию через getTower().

## Сверка с соседними модулями

Проверены resolver/attack из feature/02-combat и валидатор feature/70-content-updates. damageMul — прямой множитель (1,12 и 1,35), overlay строится суффиксом -overlay.svg, основной путь выбирается по наибольшему тиру. A1 расширяет range вместо splash: в текущем combat положительный splash у ring/pulse сжимает радиус. У echo установлен radius=100, поскольку реализация использует его и для дальности, и для перехода цепи. B4 — широкий beam вместо cone с count=1, чтобы пробитие было реальным прямым прострелом.

Текущий combat вызывает area для ring/pulse без передачи pierce (лимит не обеспечен). Числа pierce в данных задают ожидаемую контрактную границу, не доказанное фактическое число попаданий. Не меняем combat, engine, contracts, конфигурацию или чужие ресурсы. После интеграции необходимо проверить фактический лимит, взаимодействие push/mark/shred, начисление слоя один раз, ауры, активные способности и баланс волн.

## Проверки

Изолированная проверка данных: 216 комбинаций, включая 64 допустимых/152 запрещённых, 6 финальных кросс-путей, цены, T5, числовые границы и ресурсы. В предыдущем состоянии общий npm run check был успешным; после повторной ревизии в доступной среде отдельно проверены TypeScript strict по frozen contracts, матрица комбинаций в Node и отрисовка 22 восстановленных SVG. Полный npm run check для обновлённого коммита требует установки зависимостей; сетевой доступ npm недоступен. Fixture не заменяет интеграционный тест. Не утверждаем, что игровой баланс или весь проект уже проверены.

# Призменный маяк (prism)

Элементальная наземная башня. Цена постройки — **1100** кредитов, footprint — **26** пикселей. Базовая атака — мгновенный энергетический **beam**, 15 урона раз в 0,3 с, дальность 185, одна цель, без обнаружения скрытых, 50 условных DPS до сопротивлений, щита и брони. Все цены ниже — отдельная покупка на normal, без скидок.

Важное уточнение: у T3/T5 указана **основа replaceAttack**. По правилам контракта после выбора этой основы применяются **все** накопленные delta на обеих выбранных ветках. ## Проверка условного DPS и капиталовложений

Чисто аналитический верхний предел при непрерывной стрельбе, точных попаданиях всех лучей и без потерь на смене цели. Урон считается как damage × count / interval с накопленными delta; **не** учитываются сопротивления, броня, щиты, невостребованное пробитие, ограничения целей, перенацеливание, поддержка соседей, активные способности или собственная метка. Это **не симуляция и не доказательство проходимости карт**. Для focus указана скорость до накопления, а максимум — отдельно.

## Область действия DSL

- **Beam** разрешает мгновенную атаку, а `count` задаёт число самостоятельных лучей, `pierce` — максимум уникальных целей одной прямой атаки. В отсутствие достаточного числа целей расчёт DPS с несколькими лучами является верхней границей. Правило распределения независимых лучей принадлежит общей реализации combat; поля для принудительного выбора разных целей в AttackDef v1 нет.
- **Focus** хранит непрерывность атаки по цели у источника. При потере непрерывности эффект не должен мгновенно считаться заряженным; T1/B1 кросс не обещает независимого focus на обе цели. Время достижения A5 cap — 6 с при сохранении цели.
- **Mark** использует единое базовое правило +10% входящего урона, не умножается на число наложений. **Reveal** держится 3 с; **detect** работает для союзных построек в радиусе соответствующей ауры. C2 использует mark 3,5 с. Усиления одной stat от разных поддержек заменяются сильнейшим значением; собственная C-аура не усиливает исходную башню.
- Ауры C5: `damage=0.36` ниже лимита 0,40, `attackSpeed=0.25` ниже лимита 0,50. Один и тот же `effect.id` на T3/T4/T5 **заменяется**, а не складывается. Активные `nova` и `overclock` используют штатные AbilityDef и cooldown; не запускаются автоматически, не требуют расширения combat.
- Все статусы и числовые эффекты находятся в штатных `addStatuses`, `delta`, `effects`, `replaceAttack` и `abilities`. Нет новых команд, денег, скрытых периодических атак, собственных таймеров или функций поведения в контенте.

## Художественные ресурсы

Каталог `public/art/towers/prism/`:

- Полные прозрачные SVG 128×128: `base.svg`, `a1.svg`…`a5.svg`, `b1.svg`…`b5.svg`, `c1.svg`…`c5.svg`.
- Отдельные накладки: `a1-overlay.svg`, `a2-overlay.svg`, `b1-overlay.svg`, `b2-overlay.svg`, `c1-overlay.svg`, `c2-overlay.svg`.
- `preview.html` — локальная галерея всех 16 полных видов, шести вариантов T5+T2 и шести отдельных вторичных накладок, без внешних зависимостей.

Визуальный язык: медное основание, сине-зелёный стеклянный сердечник; A вытягивается в обелиск с единой белой линзой; B распускает спектральные оптические лепестки; C достраивает три яруса и вращающиеся печати. Искажать hitbox в зависимости от SVG нельзя; footprint неизменен. Визуальные ключи `muzzle/projectile/impact` в данных — логические идентификаторы геометрических эффектов renderer, не сетевые ресурсы.

Для финальных 5–2–0 и 2–5–0 берётся полный вид основной ветки `<main>5.svg`, затем накладывается `<secondary>2-overlay.svg` в тех же координатах 128×128. Для промежуточного кросса применяются накладки secondary T1 или T2. Путь `ResolvedTower.secondaryOverlay` заполняет общий combat-resolver — непосредственно в TowerDef v1 отдельного поля для кросс-картинок нет. В юнит-тестах это проверяется отдельным fixture resolver по правилам v1.

## Проверка

```bash
npm ci
npm run check
npx vitest run tests/towers/prism.test.ts
```

Тесты самостоятельно проверяют цены и ID, независимость выдачи `getTower()`, значения T1/T2/T5, все допустимые комбинации tiers по frozen `legalTiers`, шесть максимальных кросс-путей, конечность чисел, caps поддержек, 22 уникальных SVG и присутствие моделей в галерее.

На заданном базовом коммите общий `src/combat/index.ts` ещё является заглушкой. Отдельная ветка `feature/02-combat` содержит полноценный resolver, поддержку focus, mark, reveal, nova и overclock (повышение темпа, не прямого урона). Контентные тесты остаются изолированными от чужой ветки. Они **не** заменяют реальный прогон боёв, столкновений, проигрывания abilities, UI, replay или сохранений. При общей интеграции остаются проверки: распределение count-лучей, накопление/сброс focus, mark/reveal, приоритет аур, таймеры активных способностей, отрисовка secondaryOverlay, 1×/3× и reducedMotion.

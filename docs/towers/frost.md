# Криокристалл / Frost

**Контракт:** v1 · **модуль:** `src/content/towers/frost.ts` · **ID:** `frost`.

Криокристалл доступен уже на первой карте. За 500 кредитов игрок получает одиночный ледяной снаряд с 5 урона, интервалом 0,9 с, дальностью 155 и замедлением 24% на 1,7 с. Размещается на суше (`land`), footprint 26. Не является поддержкой или доходной постройкой.

Все цены — независимые покупки на `normal`, без скидок. Параметры T3–T5 в таблице заданы для `replaceAttack` **до** накопленных `delta` T1/T2 и вторичной ветки. Полные числа данных хранятся в TypeScript; таблица ниже учитывает применение дельт.

### Почему T5 — новая механика

- **A:** вместо направленных попаданий и всплесков вся круговая зона получает периодические ледяные импульсы; отдельная командная способность «Корона зимы». Повторная заморозка подчиняется общей устойчивости к жёсткому контролю, включая боссов.
- **B:** `count=3` — три независимых кинетических снаряда с осколочной зоной каждого и бронепробитием; `echo` обновляется по своему ID, не складывается с прежней ступенью и не копирует себя. В `combat` уже определено условие **frost/slow + kinetic → +10%** по заранее замедленным целям. Специальную проверку внутри башни добавлять не нужно.
- **C:** после `ring` башня переходит на `pulse`; медленные волны поражают всю локальную зону. Три спутника — читаемая модель источников импульса, **не** три скрытых дополнительных экземпляра урона. Активная «Полярная буря» — одноразовая nova с перезарядкой.

## Численная оценка специализаций

Все значения предполагают, что цель непрерывно находится в зоне и атака не простаивает; нет брони, щита, сопротивления, промахов, штрафов сложности, усилений союзников, эхо-попаданий или активной способности. Для B указана **сумма урона трёх отдельных снарядов при наличии целей**, не гарантированный DPS одной цели. Для A/C periodic AoE указан DPS **на каждого подходящего противника в радиусе**, не суммарный урон по произвольной толпе. Стоимость включает базовые 500 кредитов и все выбранные ступени.

Базовая формула прямого DPS — `damage × count / interval`. A5, B5, C5 учитывают T1/T2 своих веток; скорость атаки в A2 умножает интервал на `0.86`. Для B дополнительно возможны бонус +10% по уже замедленным целям, урон эхо, множители щита/босса; они **не входят** в столбец DPS. Размер `splash` с C1/C2 влияет на направленные снаряды, но для `ring`/`pulse` главным радиусом остаётся `range`, а не добавочный всплеск. Боссы имеют свою устойчивость к остановке, не допускается бесконечная цепь заморозок.

## Резолвер, вторичная ветка, графика

Контракт предписывает:

1. Выбрать наиболее высокую `replaceAttack` основной ветки с T3 или выше; на T1/T2 замен атаки нет.
2. Применить **все** накопленные `delta` путей A, B, C, по возрастанию ступеней каждого пути; затем объединить `addStatuses` по виду/источнику, эффекты и способности по `id`.
3. При пути 5–2–0 основным всегда остаётся путь 5. Два ненулевых пути до T3 выбирают основной по меньшему индексу.
4. `secondaryOverlay` берётся из `/art/towers/frost/cross-<main>-<secondary>.svg`, где буквы `a`, `b`, `c`. Накладка совмещается поверх полного SVG основного пути с тем же viewBox `0 0 240 240`.

| Основной путь | Вторичный путь | Накладка |
| --- | --- | --- |
| A | B | `cross-a-b.svg` |
| A | C | `cross-a-c.svg` |
| B | A | `cross-b-a.svg` |
| B | C | `cross-b-c.svg` |
| C | A | `cross-c-a.svg` |
| C | B | `cross-c-b.svg` |

В папке `public/art/towers/frost/` лежат самостоятельные полноразмерные `base.svg`, `a1..a5.svg`, `b1..b5.svg`, `c1..c5.svg`, шесть прозрачных кросс-накладок и `preview.html`. Все рисунки векторные, состоят из фигур с внутренними градиентами, не загружают внешний контент. `VisualState` задаёт отдельные образцы атаки/попадания и фазы движения; текущий frozen API содержит эти строки как визуальные токены, но настройка общего renderer/motion принадлежит интегратору. Конкретные снаряды не представлены обещанием о готовом чужом renderer.

## Ограничения синергий и экономики

- Legal tiers: не более двух ненулевых веток, не более одной выше T2. Три ветки одновременно, 3–3–0 и две пятые запрещены. Один командный слот T5 каждого пути; проверяет общая симуляция.
- Frozen DSL не задаёт отдельный «накопленный шанс заморозки», индивидуальный escalating resistance, вероятностную шрапнель или новый обработчик условного урона. Поэтому A опирается на штатные иммунитеты `freeze`, B — на штатную синергию `slow + kinetic`, C — на `ring/pulse/nova`, а не на непроверенные собственные события.
- Резолвер не должен дублировать `echo` после апгрейда B4 → B5: ID у эффекта один. Эхо ограничено `cap`, не рекурсивно; не создаёт денежную награду само по себе.
- Нет auras, income, interest, harvest или влияния на продажу; пассивный доход 0 на всех состояниях. Возврат — только `floor(0.7 × invested)`. Замедление никогда не гарантирует менее 25% исходной скорости, боссовое freeze ограничивается runtime.
- Урон `count=3` распределяется по независимым выстрелам и целям по общей боевой механике. Нельзя приравнивать его к тройному урону одной цели без реальных трёх попаданий.

## Проверки модуля

Команды из корня репозитория:

```sh
npx vitest run tests/towers/frost.test.ts
npm run typecheck
npm run check
```

В `frost.test.ts` есть отдельный fixture resolver с проверкой полного конечного пространства legal tiers и переходов, шести 5–2–0, ID/цен/статусов/числовых границ, отсутствия двойного `echo`, независимых копий `getTower` и существования всех 22 SVG. Галерею можно открыть как `public/art/towers/frost/preview.html` без сервера. SVG также проверяются Inkscape при экспортировании контактного листа; это визуальный контроль, а не e2e игры. Combat-модуль и полный engine остаются отдельными несвязанными модулями и не подменяются заглушками из данного каталога.

# Обсерватория (`observatory`)

Самостоятельная поддерживающая постройка, открываемая после Старого акведука. Категория `support`, установка только на суше, цена 650, footprint 26, базовая атака 0 урона / 1 с / 190 дальности. Уже на базовом уровне выдаёт союзным башням обнаружение скрытых в радиусе 190: `aura(stat='detect', power=1)`. Сама себя аурой не усиливает. Её начальная функция не зависит от наличия у неё боевой атаки.

## Интерпретация DSL и ограничения сочетаний

- До T3 замен атаки нет. Самая высокая `replaceAttack` T3–T5 является источником боевого режима; вторичный путь до T2 не меняет первичный силуэт и режим атаки.
- Сначала определяется атака основной ветки, затем применяются `delta` всех купленных уровней по порядку A→B→C. Поэтому цифры `replaceAttack` и готовой сборки отличаются. `effects` с одинаковым ID заменяют предыдущее значение: обнаружение растёт без накопления независимых детекторов.
- Ауры всех разных башен с одной характеристикой **не суммируются**: применяется наибольший бонус для каждой характеристики. Глобальный предел скорости поддержек +50%, урона +40%, скидки +15%. У этой башни скидки нет. Дальность, обнаружение и бронепробитие тоже выбирают сильнейший источник своего stat.
- Самоусиления отсутствуют: поддержка не применяется к своей башне. Множитель урона C1 и скорости C2 — собственные `delta` на атаку, а не самоприменение ауры.
- `reveal` лишь раскрывает скрытность на ограниченное время; `mark` даёт +10% входящего урона и не складывается до бесконечности (сильнейшая метка заменяет слабую). Эффекты обновляют длительность через максимум, а не суммируют. Они наносятся только реальной успешной атакой.
- `ring` — периодическая локальная волна; `beam` поражает прямую линию до `pierce` уникальных врагов; `chain` начинает с выбранных врагов и совершает ограниченное число переходов внутри `chainRadius`. Число `count=2` означает независимые лучи/цепи с распределением целей боевым модулем.
- Обнаружение в базовой ауре помогает **соседним** башням, а не самим врагам; для прямого раскрытия нужны кольца A3+ и успешное попадание, а для своих атак без раскрывающего кольца — A2 (`detects=true`). Не обещается автоматическое обнаружение на всей карте.
- У всех эффектов нет `income`, `interest`, `harvest`, `echo` и повторно запускающихся аур. Нет активной способности, способной обходить режим `no-actives`. Нет восстановлений жизней, возврата, бесконечного контроля, временных задержек и экономических циклов.
- T5 меняют не только цифры: A открывает увеличенное всенаправленное кольцо и дальнее обнаружение; B ведёт две независимые линии, пронизывающие до девяти целей каждая; C строит две цепные сети по семь целей с массовой маркировкой.

## Графика и подключение

`public/art/towers/observatory/`: 16 полных SVG 128 × 128 (`base.svg`, `a1`–`a5`, `b1`–`b5`, `c1`–`c5`), 6 прозрачных накладок (`a1-overlay`, `a2-overlay`, `b1-overlay`, `b2-overlay`, `c1-overlay`, `c2-overlay`) и `preview.html`. Пивот в центре (64,64), геометрия сохраняется внутри поля, ресурсы автономны. T5 сохраняет footprint 26 независимо от размера купола/астролябии/звёздной карты.

У полной модели `VisualState.asset` — абсолютный публичный путь. Для финальной пары рендерер берёт модель T5 основной ветки и накладывает поверх `<secondary-path><secondary-tier>-overlay.svg`; `ResolvedTower.secondaryOverlay` возвращает такую ссылку. Функция `getTower()` не зависит от DOM/изображений и создаёт независимые данные при каждом вызове. Дополнительных файлов общего реестра/контрактов менять не требуется.

## Проверки и статус

- `npx vitest run tests/towers/observatory.test.ts`: структура, ID, цены, семантика DSL, база, все 64 допустимые комбинации и отбраковка 152 запрещённых, шесть T5-кроссов, экономика, активы.
- `npm run check`: TypeScript strict, штатные тесты и production build.
- SVG: экспортированы все 22 ресурса через Inkscape; контактные листы 16 полных моделей и шести финальных сочетаний просмотрены. Различимость начальных T1/T2, силуэтов T5 и накладок проверена визуально при 256 px.
- Независимый тестовый `fixtureResolve` повторяет публичную последовательность разрешения по frozen-контракту. Это проверка **каталога**, а не доказательство работы ещё не реализованного общего `src/combat/index.ts`, который в базовом коммите выбрасывает исключение. Честное измерение DPS по реальным волнам, взаимодействие с противниками и проверка engine/renderer остаются на общей интеграции. Локальные расчёты не выдаются за результаты проигрыша боя.

Публичный API модуля: `getTower(): TowerDef` из `src/content/towers/observatory.ts`. Не требуется менять существующие контракты, боевую систему или проектные скрипты.
